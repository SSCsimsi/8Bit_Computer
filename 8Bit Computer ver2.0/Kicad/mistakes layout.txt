

* General -------------------------------------------------------------------------------

  registers do not need the and gate connecting the inverted clock signal to the store command in front of their clock input, as the registers only react to a rising edge on their clock input

 

* ALU -----------------------------------------------------------------------------------

! the command 0x1E / STA / Store Flags does not need a connection to DAT_dis as it does not output anything to the data bus

- Flag Register
! the lines from the 2 d-latches (latch 2 of IC130 and latch 1 of IC131) are switched - 2Q\ of IC130 should be connected to OE\ of the bus interface and 1Q should be connected to 2B of IC132

- Comparator
! the and gate for A<B should have the inverted outputs from the comparator as inputs, so it should be P=DAT\ and P>DAT\

- Barrel Shift Register
! the SFC line should be connected to the STC line (there was probably a naming error, as both combined would be the SFC line from the simulation)

- Adder/Incrementor
  the bus interfaces for splitting up the subtraction signals are not needed



* CPU -----------------------------------------------------------------------------------

- Programme Counter
! the conditional jump command should not be inverted as it goes into the d latch clock input (IC265)

- RAM
